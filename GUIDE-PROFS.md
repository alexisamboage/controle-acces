# Guide pour les profs : Contrôle d'accès

L'app permet de vérifier en quelques secondes si une personne présente au cours est inscrite dans l'un des clubs partenaires. Elle fonctionne **sans internet** une fois la liste importée. Chaque téléphone garde ses propres données : rien n'est partagé entre les téléphones.

**Lien de l'app :** https://alexisamboage.github.io/controle-acces/

## 1. Installer l'app (une seule fois, avec du réseau)

**Android (Chrome)**
1. Ouvre le lien dans **Chrome**. S'il s'ouvre dans WhatsApp, touche ⋮ puis « Ouvrir dans Chrome ».
2. Touche ⋮ (en haut à droite), puis **Ajouter à l'écran d'accueil**, puis **Installer**. Ne choisis pas « Créer un raccourci ».
3. Si Chrome affiche « Impossible d'installer », recharge la page (⟳) et recommence.

**iPhone (Safari obligatoire)**
1. Ouvre le lien dans **Safari**. S'il s'ouvre dans WhatsApp, touche l'icône boussole ou « Ouvrir dans Safari ».
2. Touche le bouton **Partager** (le carré avec une flèche vers le haut), puis **Sur l'écran d'accueil**, puis **Ajouter**.
3. Ouvre ensuite toujours l'app avec **l'icône Yamabushi**, pas depuis Safari : l'app et Safari ne partagent pas les mêmes données.

## 2. Importer la liste des membres

1. Enregistre sur ton téléphone le fichier Excel reçu par WhatsApp.
   - **Android :** ouvre le fichier dans WhatsApp, il est alors enregistré dans « Téléchargements ».
   - **iPhone :** ouvre le fichier, touche **Partager**, puis **Enregistrer dans Fichiers**.
2. Dans l'app, va dans l'onglet **Liste**, touche **Importer le fichier Excel** et choisis le fichier.
3. Vérifie le résumé : le nombre de membres par club.
4. La fenêtre **Bienvenue** te demande ton club, ton prénom et l'email de l'administration. Mets l'adresse qui t'a été envoyée avec le lien.

Quand tu reçois une nouvelle liste, importe-la de la même façon : elle remplace l'ancienne.

## 3. Faire le contrôle pendant le cours

1. Dans l'onglet **Contrôle**, tape au moins 2 lettres du nom ou du prénom, dans n'importe quel ordre.
2. **Vert = inscrit.** Touche le nom pour voir le club et l'année de naissance.
3. **Rouge = non trouvé.** Essaie d'abord le prénom seul, puis le nom seul, et regarde les **« Noms proches ? »** proposés.
4. Si la personne n'est vraiment pas dans la liste, touche **Noter comme non inscrit**. Remplis le nom et, si possible, le téléphone et l'email (ceux d'un parent pour un enfant), puis touche **Enregistrer**.
5. Touche **✉ Prévenir l'administration** : l'app email s'ouvre avec le message déjà écrit. Touche **Envoyer**. Sans réseau, l'email partira tout seul plus tard.

## 4. Exporter les non-inscrits

Dans l'onglet **Non-inscrits**, touche **Exporter en Excel** et envoie le fichier par WhatsApp ou par email. Quand tout le monde a été relancé, touche **Vider la liste**.

## Bon à savoir

- **Mises à jour :** l'app se met à jour toute seule quand le téléphone a du réseau. Ta liste et tes non-inscrits sont conservés.
- **Sur iPhone :** si le téléphone manque de place, l'iPhone peut effacer les données de l'app. Réimporte alors la liste. Exporte régulièrement les non-inscrits pour ne pas les perdre.
- **Protection des données :** la liste contient des noms d'enfants. Ne la transfère à personne d'autre et supprime l'ancien fichier de WhatsApp après l'import.
